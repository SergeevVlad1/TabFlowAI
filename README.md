TabFlowAI — Smart Tab & Task Manager

TabFlowAI — это расширение для браузера, которое помогает организовать ваше рабочее пространство и управлять задачами прямо во вкладках. Оно автоматически упорядочивает вкладки по категориям и помогает сосредоточиться на том, что действительно важно.

🚀 Основные возможности

📂 Умная группировка вкладок
TabFlowAI автоматически группирует вкладки браузера по категориям, например:

Работа
Учеба
Игры
Развлечения
и другим, чтобы ваше рабочее пространство оставалось чистым и организованным.

✅ Менеджер задач
Создавайте и управляйте задачами прямо внутри расширения:

добавляйте новые задачи
удаляйте ненужные
отмечайте задачи как выполненные

📊 Статистика продуктивности
Следите за своей продуктивностью:

сколько задач выполнено
сколько времени потрачено
ваша общая эффективность

⚙️ Настройки и персонализация

профиль пользователя
переключение темы
выбор модели AI (в будущих версиях)

🤖 AI-ассистент (в разработке)
В расширении предусмотрен AI-ассистент, который в будущих обновлениях поможет:

планировать задачи
управлять вкладками
повышать продуктивность
